# File Purposes

View **[dir_tree.txt](dir_tree.txt)** for the folder structure, excluding markdown and some text files

---

**anim-shadow-rmv.html**: to remove shadows found in animation frame assets to keep a clean look

**anim-tool.html**: to align and uniform size of animation frame assets that are various in size or position

**audio.py**: audio manager/handler

**boss.py**: boss, arena, and cinematic boss animation manager

**commands.py**: console commands processor/parser

**console.py**: developer console core logic and history commands

**cursor_tester.py**: custom cursor size/offset tester

**enemy.py**: enemy manager; geometry, enemy logics, rendering

**image_mirror_tool.html**: to adjust animation frame assets

**main.py**: main game logic

**maze_viewer.html**: to view mazes (saved_maze.json) saved from the game

**maze.py**: maze generation and path finding

**mckPy.py**: graphics wrapper

**player.py**: movement, attacks, wall/enemy collision, rendering

**rendering.py**: a few helper functions to render wall shadow, fog vision, and tile image

**saved_maze.json**: saved maze from game

**settings_io.py**: settings export and import

**settings.json**: saved settings from game

**tile_gen.py**: script used to generate all path tiles with only two images of grass and dirt

**Trajan-bold.otf**: bold font

**Trajan-regular.ttf**: regular font

**ui.py**: UI helpers and menu rendering components
